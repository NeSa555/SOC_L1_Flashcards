# SOC Analyst Flashcards

A simple flashcard website created to support my learning of SOC and cybersecurity fundamentals.

## Features
- Interactive question-and-answer flashcards
- Next and previous navigation
- Shuffle cards
- Mark cards as known or needing review
- Save learning progress in the browser

## Technologies
- HTML
- CSS
- JavaScript
- Browser `localStorage` for saving progress

## How to Use
Open the website, review each question, reveal the answer, and mark whether you know the concept or need to review it again.

## Purpose
This is a beginner learning project built while studying SOC fundamentals. It helps me practise cybersecurity terminology and develop basic web development skills.
